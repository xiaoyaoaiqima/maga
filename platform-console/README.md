# MAGA Console

MAGA 平台管理台前端项目。

## 技术栈

- **Vue 3** - 渐进式 JavaScript 框架
- **Vite** - 下一代前端构建工具
- **TypeScript** - JavaScript 的超集
- **Ant Design Vue** - 企业级 UI 组件库
- **Pinia** - Vue 状态管理
- **Vue Router** - 官方路由管理器

## 功能特性

- 多主题色切换
- 国际化支持
- 动态路由权限
- 响应式布局

## 安装与使用

### 环境要求

- Node.js >= 20.12.0
- pnpm >= 10.0.0

### 安装依赖

```bash
pnpm install
```

### 开发运行

```bash
pnpm dev
```

### 构建打包

```bash
pnpm build
```
