## 2. qwen-plus 语义改写

这些表达通常可以修好，不进入硬禁词，也不做字符串替换。改写必须保留原人物、来源、活动机制、奖品归属和每批检测信息；改写丢事实时拒绝候选并保留原文。

- AI连接词、负担表达或福利黑话：顺手、顺口、顺便、麻烦、薅、白嫖、羊毛、真的会谢、彩虹屁、挺逗、Emm、笑哭R。
- 页面动作：顺便看到、往下翻、翻着翻着、往下滑、仔细翻、翻了翻活动页面、带一嘴。
- 检测来源承接：只有当“活动页面、页面里、页面上”和每批检测出现在同一句时才触发改写；普通活动规则描述不拦。
- 可软化的负面状态：厌奶、断奶、见底、快喝完、痛苦、生气、烦躁、麻烦、接不上、应付。
- 需要根据上下文重写：两份、另一份、虽然不大、活动值得囤、让宝爸也一起、闻闻、啃、搬。
- 渠道或地域人格：抖音、朋友圈、淘宝、拼多多、东北、北京、四川、重庆、广东、深圳、广州、江浙沪、浙江、江苏、上海、山东、河南、河北、福建、闽南、西安、陕西。朋友圈可自然改成`puq`或`pyq`；只有模型无素材新增地域或渠道时才改，不把自然原始来源机械删除。
- 表达过于拟人或夸张：给a2写感谢信、给a2至初写感谢信。可改成普通消费者认可，但候选必须重新审核。

本层默认使用 qwen-plus 的运营反馈改写链路。示例：`有羊毛` 可以结合整句改成 `有福利` 或 `活动福利挺好`，不能建立 `羊毛 -> 福利` 的代码字符串替换。

## 3. 硬拦截

### 3.1 可直接按词面拦截

- 供应与风险：没货、缺货、召回、买不到、断货、断供、不好买、又没了。
- 指令或字段泄露：正文、标题、卖点、痛点、问配方、填表、自己账号。
- 绝对或无依据检测：无限、全检、A2蛋白质检测、生产批号、新码。
- 旧罐/空罐参与：空罐、攒着罐子、攒罐子。
- 明确机制错误：扫罐底码就能抽奖、一罐小车车、婴儿车抽奖。

### 3.2 只在活动奖品或机制语境中硬拦截

- 赢一辆：如果把集罐兑换写成抽奖赢车，判机制错误；普通口语不能只按词面判断。
- 积木、拉链包、小玩具、小书包、辅食碗、贝亲：只有被写成活动奖品时才判新增奖品，普通生活场景不按词面拦截。
- 专利、专属、A2源乳：只有形成未确认活动事实、产品事实或认证事实时才拦截，不能单独作为全局禁词。

## 4. 当前不采用为禁词

这些词与已确认业务口径冲突或覆盖面过大，不进入礼遇活动硬禁词：

- 生病、便秘、抵抗力：疾病或医疗效果在本活动审核中已明确允许表达。
- 产品：原始活动素材存在“兑换1罐产品”等自然用法，不能词面封禁。
- 避免：普通连接词，单独封禁会产生大量误杀。
- 眼脑：需要结合具体成分和表达判断，不能只按词面判错。
- 专属、专利：按事实语境审核，不做词面硬禁。
- 见底、快喝完：本身可以是自然库存状态；只有被用于暗示旧罐参与或制造断供焦虑时才改写。
- 地域名称：原始素材明确给出时可以保留；只处理模型无依据新增的地域人格。
- 两份、另一份：需要判断奖品数量和指代对象，不能只按词面判错。

## 执行原则

1. 硬禁词只收事实、机制、风险和指令泄露等确定性问题。
2. 能自然修复的口语、渠道、页面动作和情绪表达走 qwen-plus，不加入字符串 replacement。
3. 模型改写必须做 before/after 事实保留检查；丢失段落、人物、活动机制或检测信息时拒绝改写。
4. 生成提示中的避用词、运营候选词和正式审核硬规则分开维护。
5. 未明确列入硬拦截的词不得自动升级为 hard ban。
