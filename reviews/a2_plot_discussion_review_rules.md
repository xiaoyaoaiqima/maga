# A2 剧情讨论评论审核规则

用途：记录 A2 剧情讨论评论的人工审核口径和运营反馈校准点。下次审核新产物或吸收运营反馈时，先看本文件，再把稳定规则同步到 `skills/xhs-maternal-infant-ugc-review/SKILL.md`；如果规则会影响生成，再同步到 `关键词语料/评论业务规则_剧情讨论_子关键词导出.csv`。

## 当前稳定口径

- 剧情讨论只单独审核 `context_list.评论业务规则 == "评论业务规则-剧情讨论"` 的评论。
- 产品向评论可以保留，不因为缺少剧情锚点被判为剧情问题；除非用户明确要求整批路由检查。
- `小奶宝找妈妈`、`帮小奶宝找妈妈` 是正确剧情主线，不单独判错。
- 如果上文问 `小奶宝找到妈妈没`，第3集口径是已找到或团聚，要直接回答剧情事实。
- 孩子可以被剧情带动，念叨通讯器、呼叫队友、救援、秘密侦探、寻宝、巡逻等玩法。
- 孩子不要知道门店活动机制，也不要主动要求 `买4罐加赠对讲机/赠品`；补货应由妈妈侧自然发起，不要写成孩子催买奶粉。
- 活动信息优先由妈妈侧知道，例如准备补货前问店员、路过门店看到、宝妈群或闺蜜转述；如果已经写到补货/到店买4罐，则要写成领到、拿到或带回对讲机。
- A1/A2 可以作为剧情知识点或童言童语出现，但不要写成营养科普、确定健康功效、`A2打败A1怪兽`。
- 当前剧情讨论要拉大艾尔博士讲 A1/A2型奶牛的比重，审核时不要把自然出现的艾尔博士、A1/A2、A2型蛋白质、稀有A2型奶牛都当成产品硬植入；只有写成功效科普或确定健康结论时才打回。
- 短句、库存消息、群里/闺蜜/朋友转述、怕跑空、明天去看看、问店员还有没有活动都可以放行；只在同类短句扎堆、格式坏、语义不通、明显硬广、具体店名占位或功效风险时标问题。
- 对讲机活动的状态要一致：未到店/准备去时可以 `问问活动`、`看看有没有`、`怕跑空`；已经补货、已囤或买4罐时，不应再写 `顺手看了眼对讲机周边`、`看看有没有对讲机`，而应写成买4罐加赠、领到、拿到或带回定制对讲机。
- 对讲机款式表达不必每条都写全称。可以写 `巴克队长&艾尔博士款`、`巴克队长款对讲机`、`艾尔博士款对讲机`、`定制对讲机`、`这套周边`、`同款对讲机`、`那套对讲机`。不要缩成缺少 `款` 字的 `巴克队长对讲机`、`艾尔博士对讲机` 或 `巴克队长&艾尔博士对讲机`；`同款对讲机`、`那套对讲机` 只在批量高频时按同质化提示。
- 对讲机活动事实写 `购买4罐/买4罐加赠`，不要写成 `买4罐送`；如果是问问、看看、怕跑空，要明确是补货前/去店前，不要写成补货时才问或看。
- 短评论装不下完整款式时，可以写 `定制对讲机/这套周边`，但不能截断成 `对讲` 这类半个词。
- A2 剧情讨论现在每条都要有轻剧情锚点和门店活动引流，不能只说剧情。门店活动引流可以是妈妈侧补货前问活动、顺路去门店、怕跑空先确认、宝妈群提醒、家里快喝完去续奶粉、到店领取周边等。
- `补货买4罐` 这个连写结构同质化高，批量生成时应减少。可以轮换成 `家里快喝完了`、`去门店把奶粉续上`、`按活动带够4罐`、`四罐一起带`、`凑够活动门槛`、`到店参加活动`、`顺路问问活动`、`带回定制周边`。
- `问问门店活动还在不在`、`活动还在不在` 可以说，问题是批量里高频同质化。可轮换成 `群里有人晒了`、`问店员还有没有`、`去店前打听下`、`怕跑空先问问`、`顺路去门店瞅瞅`、`正好要补货`。
- `确认那套对讲机/确认那套周边`、`看规则/活动规则/周边规则` 表达不自然，建议改成 `问店员还有没有`、`去店里瞅瞅`、`群里有人晒了，正好补货去看看`。
- 到店/补货场景不要总强调 `同款对讲机` 或 `那套对讲机`，优先写 `去门店补货`、`续奶粉`、`按活动带够4罐`；对讲机可以自然出现，但不要每条都把门店动作绑定到同一个指代表达。
- 术语固定写 `A2型奶牛`、`稀有A2型奶牛`、`A1/A2型奶牛`；不要写成 `A2奶牛`、`稀有A2奶牛` 或 `A1/A2奶牛`。
- 剧情讨论活动表达禁止出现 `盲盒`，活动物料统一围绕定制对讲机或独家IP周边。

## 跑批交付流程

- 用户要求本地跑 A2 剧情讨论评论批次时，默认在跑完后导出 `.xlsx` 结果文件；聊天里可以贴摘要或问题样例，但不能只贴文本列表。
- `.xlsx` 至少包含序号、标题、正文、上下文变量(context_list)、模型信息、是否 fallback、初步问题标记，方便运营直接筛；明细表只导出非空评论。标题列默认空，正文列放评论正文，上下文变量(context_list) 用 JSON 字符串记录人设、扰动规则、生文指令、评论业务规则、生文输出格式，A2 剧情讨论可额外记录语料子方向。
- 如果出现空输出，只在摘要里统计空输出数量，不写入明细表，也不要用语料示例兜底替换；半句截断、完全重复、对讲机活动状态错位等非空问题保留在 `.xlsx` 中并标记。

## 打回优先级

高优先级打回：

- 上文问 `找到妈妈没`，评论没有回答已找到或团聚，反而继续写成未知或反问。
- 孩子知道门店活动机制，或孩子为了活动赠品催买奶粉。
- 孩子直接催买奶粉，导致产品/补货动作从儿童视角发起。
- 已经补货/已买4罐/已囤的语境里，还把对讲机写成只是顺手看看、问有没有或不确定能不能领。
- 对讲机写成缺少 `款` 字的 `巴克队长对讲机`、`艾尔博士对讲机` 或 `巴克队长&艾尔博士对讲机`；`巴克队长款对讲机`、`艾尔博士款对讲机`、`定制对讲机` 可以放行。
- 把 `购买4罐，在独家IP周边基础上加赠` 写成 `买4罐送`，或把补货前的问询错写成补货时才问/看。
- 对讲机、款式或活动信息被截断成半个词、半句话，导致评论语义没收住。
- A2 剧情讨论只说找妈妈、山洞求援、艾尔博士或 A1/A2 剧情知识，没有带妈妈侧门店活动引流。
- 把 `A2型奶牛` 写成 `A2奶牛`，或把 `稀有A2型奶牛` 写成 `稀有A2奶牛`。
- A1/A2 剧情点被写成功效承诺、营养结论或对抗桥段。
- 出现具体门店名、`xx店` 占位、夸张确定库存，或整句像活动通知。
- 出现 `盲盒`。

中优先级提示：

- 单条剧情锚点太少但有库存/活动信息点时可放行；批量大量重复时提示同质化。未到店口吻里的 `怕跑空/问问/去看看` 不单独打回。
- 批量里大量重复 `补货买4罐`、`补货买4罐领到` 这类固定结构时，按表达同质化提示；事实本身不打回，建议改成更生活化的到店/续奶粉/凑活动门槛表达。
- 批量里大量重复 `活动还在不在`、`问问门店活动还在不在` 这类固定问询句时，按表达同质化提示；单条自然出现不打回。建议改成群里有人晒了、问店员还有没有、去店前打听、正好补货去瞅瞅等表达。
- 出现 `确认那套对讲机/确认那套周边` 按表述不自然处理；`同款对讲机`、`那套对讲机` 只在批量高频或到店补货语境反复绑定时按同质化处理。
- 产品与剧情过渡略硬时先观察批量比例，不单条重判。
- 评论明显半句截断、语义没收住时按格式问题处理。
