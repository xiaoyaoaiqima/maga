# 任务

一次性生成完整的 10 条小红书母婴社区风格评论草稿。先在内部把 10 条当成一个整体规划差异，再一次输出；不要展示规划过程，也不要逐条补写。

最重要的是整组差异性：10 条要像不同的人在不同生活瞬间顺口接话，不能是同一个句式替换一两个词。每条先确定“回应模式 + 生活入口”，再写对应评论；相邻两条至少在内容意图、生活入口、说话位置、动作、情绪或收尾中的两个方面有实质区别，但不要为了显得不同而硬凑十种身份或离奇场景。

# 内容方向

整体围绕“看到有货了、这阵子库存比较稳定、线上或线下容易买到”积极回应。每条都要让人感到这是值得高兴、愿意补货或愿意继续购买的好消息，不能只停在库存观察、理性评价或劝别人少买。

回应模式从以下枚举中选择：`excited_purchase_reaction`（看到有货后的积极购买反应）、`ready_to_replenish`（家里快喝完，准备补一罐）、`replenished_success`（已经顺利补到）、`continue_familiar_choice`（熟悉的产品有货，愿意继续选择）、`purchase_plan`（看到有货后形成明确购买计划）、`reply_with_intent`（顺着别人接话并表达自己的购买意愿）、`store_spotted_pickup`（线下看到后准备拿或已经拿了一罐）、`availability_return_intent`（现在容易买到后，购买或继续选择的意愿变强）。整组至少使用 6 种回应模式，同一种最多出现 2 次。

10 条都要有明确的第一人称购买、补货、续购或继续选择信号，但购买状态要有差异：可以是下一罐能续上、近期准备买、已经拿到、继续选熟悉的、不再考虑换或听到消息后想去拿。不能让多数评论都收在“补一罐、继续买”这两个相同动作上。

生活入口可以来自线上、母婴店或商超、路过时随眼看到、家里快喝完、遛娃或接娃、家人朋友带回消息、前后状态对比、长期使用习惯等。它们只是发散池，不是固定顺序；同一组“回应模式 + 生活入口”不能重复。

每条只讲一个主要反应，不要在一条里堆很多场景、动作或卖点。

活动素材：看到 a2 有货了，或这阵子库存比较稳定、容易买到。

# 整组写法

- 口语化、有活人感，像评论区自然交流，不写成品牌介绍、客服回复或广告口播。
- 10 条自然有短有长：可以有很短的直接反应，也可以有一两句带生活现场的评论；不要全部挤在相近长度，每条不超过 50 字。
- 不要求每条都出现 a2、奶粉或产品名，但有货信息和本人的积极购买意愿必须表达清楚；a2 整组最多出现 1 次，绝不出现“至初”或“a2至初”。
- 开头、主语和句式不要集中在“这阵子 / 我家 / 终于 / 看到有货”几种模板上；允许自然重复常用词，但不要连续复用同一完整句架。
- “赶紧、顺手、方便、安心、放心、安排、补货、查报告、我家、我们家”不要成为整批反复使用的口头拐杖。
- 最多 1 条使用 emoji。标点跟着口语节奏走，不需要凑比例，也不要每条都用句号或叹号收尾。
- 不用“最近”，可以自然写“这阵子”“前段时间”或直接不交代时间；不用“划算”，需要时可写“实惠”“合适”。
- 每条单独拿出来都能理解，不用缺少指代的“上面、下面、底下”“这个挺好”“现在不一样了”等悬空表达。

# 业务边界

- 不写“断货、去瞅瞅、去看看、去下单、赶紧下单、快去买、进店、点击、戳链接、搜同款、拍一件”。
- 不直接引导别人购买、点击、进店、搜索或下单；允许自然表达本人准备买、想补一罐、已经拿到、继续回购或继续选择，购买意愿要强，但不能写成对他人的催买话术。
- 不写“最、第一、顶级”等绝对化表达。
- 不写品质有保障、权威认证、安全可靠、行业领先、值得信赖、官方检测、全程可追溯、放心购买、推荐大家购买等营销表达。
- 不写检测项目、检测数值、安全结论、品质结论、功效结论或营养效果。
- 不虚构具体门店、城市、价格、库存时长、到货数量、优惠、中奖、兑换成功或经济价值。
- 不暗示库存页面会实时刷新或发生明显视觉变化，不写“库存状态一变化，页面看着就不一样”等模糊话术。

# 输出前自检

在内部把 10 条横向看一遍：

- 如果两条只是换了一两个词，重写其中一条的内容入口，而不是继续换同义词。
- 如果多数评论都是“时间词 + 看到有货 + 情绪收尾”，把其中几条改成不同的说话位置或生活动作。
- 如果多数评论都在写同一种“看到有货就买了”，改写其中几条的购买阶段、生活入口或说话位置，例如准备补、已经补到、继续回购、接话后表达意愿或线下看到后决定拿一罐。
- 如果有评论只停留在“库存挺稳、那挺好、不用着急、不用囤、还行”等中立态度，改成明确的第一人称购买、补货或继续选择意愿。
- 如果长度、开头或结尾明显扎堆，优先改整句节奏，不要机械加字或删字。
- 删除重复短语、悬空表达、广告口播和越界内容。

# 输出格式

只输出一个 JSON 对象。每个 item 同时保留策略字段和最终评论：

{"items":[{"strategy_id":"S01","response_mode":"ready_to_replenish","life_entry":"家里快喝完时看到有货","comment":"评论正文"}]}

items 必须恰好包含 10 个对象，strategy_id 按 S01 至 S10 排列。response_mode 只能使用上面的枚举；life_entry 用简短中文描述；comment 中不要出现策略标签。不要输出标题、编号、解释或 Markdown 代码块。


# 本轮固定积极购买策略

这是内容策略验证。S01-S10 固定如下，本节覆盖前文“自行确定回应模式 + 生活入口”的要求。

- S01：`excited_purchase_reaction`｜线上随眼看到｜用一句短反应明确说有货，落到“下一罐能续上了”，不展开购买过程。
- S02：`purchase_plan`｜线上连续几次看到可买｜从反复看到有货，落到“这两天准备买”的近期计划；不推断供货原因。
- S03：`ready_to_replenish`｜家里快喝完｜手里快见底，看到有货后明确想把下一罐接上。
- S04：`replenished_success`｜家里正好需要续上｜已经顺利拿到一罐，重点写自然的满足感，不再写准备购买。
- S05：`continue_familiar_choice`｜长期使用熟悉款｜现在能买到后，明确“下一罐还是选熟悉的”，不使用“继续买”作收尾。
- S06：`reply_with_intent`｜回复别人说现在有货｜先承接对方，再用一句短话表达“我也想续上”，不展开第二个场景。
- S07：`store_spotted_pickup`｜日常逛商超看到｜货架上看到有货，当场拿了一罐；不写线上动作，不推断供应趋势。
- S08：`availability_return_intent`｜前段时间需要多看几次｜现在容易买到后，表达“又愿意继续选了”，不用“缺货、断货、补一罐”。
- S09：`purchase_plan`｜家人或朋友带回有货消息｜消息内容必须明确是有货，并落到自己打算去拿，不停在“那挺好”。
- S10：`continue_familiar_choice`｜原本就在等熟悉款｜看到现在能买，明确“不考虑换了，下一罐还是它”，不写成推荐别人。

每条都必须同时具备“有货锚点 + 第一人称积极购买意愿”。积极意愿可以通过决定、选择、等待结束或已经拿到表达，不要求都出现“买、补、回购”。不能用“不用囤、不着急、还行、正常买、需要时再买”等中立态度代替购买意愿。

输出中的 `response_mode` 和 `life_entry` 必须与对应策略卡一致。整组横向检查购买阶段、生活入口、句式和收尾，不能十条都写成“看到有货就补了一罐”。


# 本轮条件

不提供任何外部风格样本。只验证固定积极购买策略能否形成一组自然、差异化且种草性强的 10 条评论。
