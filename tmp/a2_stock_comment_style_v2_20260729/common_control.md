# 本轮共同控制条件

这是风格语料表示实验。为了只比较风格条件，S01-S10 的内容策略固定如下，不得互换；本节覆盖前文“自行确定回应模式 + 生活入口”的要求。

- S01：`direct_reaction`｜线上随眼看到｜只做一句即时反应，不展开后续动作。
- S02：`stock_observation`｜线上连续几次看到可买｜只说自己的库存观察，不写购买动作。
- S03：`personal_replenish`｜家里快喝完时补到｜只写自己补到一罐，不铺陈完整购买过程。
- S04：`less_hassle`｜以前需要反复确认｜重点是现在少折腾，不写具体抢购攻略。
- S05：`no_need_to_stock`｜别人提到要多囤｜表达不必刻意囤，按需要再买。
- S06：`casual_reply`｜回复别人说现在有货｜先承接对方，再补一个很小的个人观察。
- S07：`long_term_attention`｜长期使用会偶尔留意｜像老用户顺口说自己的观察习惯。
- S08：`before_after`｜前后状态对比｜写以前较难买、现在容易些，不用绝对化措辞。
- S09：`direct_reaction`｜家人或朋友带回消息｜只写听到消息后的个性反应，不追加行动链。
- S10：`stock_observation`｜日常逛商超时看到｜只写当下观察，不推断供货原因或趋势。

除当前策略卡明示的最小场景外，不补充人物关系、使用时长、渠道、数量、后续动作、供货原因或其他可核验经历。生活入口只写到足以成立，不扩成完整小故事。

输出中的 `response_mode` 和 `life_entry` 必须与对应策略卡一致。整组仍需横向检查，不能因为策略已固定就写成十个相同句架。
