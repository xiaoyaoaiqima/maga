# C 组：整组共享纯句面特征

下面 10 个句面特征与 B 组真人原句同源，但不提供原句语义。它们只控制表面节奏，不提供内容策略、身份或事实。

这些特征是整组共享池，不与 S01-S10 绑定。先严格完成本条内容策略，再自由选择最多一个兼容特征；不自然时可以完全不用，不要求精确覆盖。

- F01：一个英文口语词独立成句，用全角叹号收尾。
- F02：两字肯定短句，用一个叹号强收尾。
- F03：四字反问短句，不加标点。
- F04：先给轻程度判断，再把对象放到句尾，形成轻微口语倒装。
- F05：短反应后用逗号接一句礼貌收尾。
- F06：三拍节奏：短回应、轻笑、一个自然叠词；不要新增互动身份。
- F07：名词作主语，用“很 + 口语形容词”完成一句短评价。
- F08：模态确认短句，不加标点。
- F09：短评价加一个句尾粒子，最多带一个普通 emoji。
- F10：两字口语词后接连续笑声，不加标点；不要新增后续动作。

不要为了套特征写出不自然的英文、叠词、网络词或 emoji。
