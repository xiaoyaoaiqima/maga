# 任务

一次性生成完整的 10 条小红书母婴社区风格评论草稿。先在内部把 10 条当成一个整体规划差异，再一次输出；不要展示规划过程，也不要逐条补写。

最重要的是整组差异性：10 条要像不同的人在不同生活瞬间顺口接话，不能是同一个句式替换一两个词。每条先确定“回应模式 + 生活入口”，再写对应评论；相邻两条至少在内容意图、生活入口、说话位置、动作、情绪或收尾中的两个方面有实质区别，但不要为了显得不同而硬凑十种身份或离奇场景。

# 内容方向

整体围绕“看到有货了、这阵子库存比较稳定、线上或线下容易买到”自然回应。

回应模式从以下枚举中选择：`direct_reaction`（短反应）、`stock_observation`（观察库存）、`personal_replenish`（自己的补到经历）、`less_hassle`（感叹少折腾）、`no_need_to_stock`（不用刻意囤）、`casual_reply`（顺着别人接话）、`long_term_attention`（长期使用会留意）、`before_after`（前后状态对比）。整组至少使用 6 种回应模式，同一种最多出现 2 次。

不要让“看到货后买了多少、囤了多少”成为整组主线，`personal_replenish` 只能是其中一部分。

生活入口可以来自线上、母婴店或商超、路过时随眼看到、家里快喝完、遛娃或接娃、家人朋友带回消息、前后状态对比、长期使用习惯等。它们只是发散池，不是固定顺序；同一组“回应模式 + 生活入口”不能重复。

每条只讲一个主要反应，不要在一条里堆很多场景、动作或卖点。

活动素材：看到 a2 有货了，或这阵子库存比较稳定、容易买到。

# 整组写法

- 口语化、有活人感，像评论区自然交流，不写成品牌介绍、客服回复或广告口播。
- 10 条自然有短有长：可以有很短的直接反应，也可以有一两句带生活现场的评论；不要全部挤在相近长度，每条不超过 50 字。
- 不要求每条都出现 a2、奶粉或产品名，只要有货状态和个人反应表达清楚即可；a2 整组最多出现 1 次，绝不出现“至初”或“a2至初”。
- 开头、主语和句式不要集中在“这阵子 / 我家 / 终于 / 看到有货”几种模板上；允许自然重复常用词，但不要连续复用同一完整句架。
- “赶紧、顺手、方便、安心、放心、安排、补货、查报告、我家、我们家”不要成为整批反复使用的口头拐杖。
- 最多 1 条使用 emoji。标点跟着口语节奏走，不需要凑比例，也不要每条都用句号或叹号收尾。
- 不用“最近”，可以自然写“这阵子”“前段时间”或直接不交代时间；不用“划算”，需要时可写“实惠”“合适”。
- 每条单独拿出来都能理解，不用缺少指代的“上面、下面、底下”“这个挺好”“现在不一样了”等悬空表达。

# 业务边界

- 不写“断货、去瞅瞅、去看看、去下单、赶紧下单、快去买、进店、点击、戳链接、搜同款、拍一件”。
- 不直接引导别人购买、点击、进店、搜索或下单；减少“买”“下单”，可自然使用有货、到货、囤着、补到、库存稳了等表达。
- 不写“最、第一、顶级”等绝对化表达。
- 不写品质有保障、权威认证、安全可靠、行业领先、值得信赖、官方检测、全程可追溯、放心购买、推荐大家购买等营销表达。
- 不写检测项目、检测数值、安全结论、品质结论、功效结论或营养效果。
- 不虚构具体门店、城市、价格、库存时长、到货数量、优惠、中奖、兑换成功或经济价值。
- 不暗示库存页面会实时刷新或发生明显视觉变化，不写“库存状态一变化，页面看着就不一样”等模糊话术。

# 输出前自检

在内部把 10 条横向看一遍：

- 如果两条只是换了一两个词，重写其中一条的内容入口，而不是继续换同义词。
- 如果多数评论都是“时间词 + 看到有货 + 情绪收尾”，把其中几条改成不同的说话位置或生活动作。
- 如果多数评论都在写去店里、买到、拿了或囤了，把其中几条改成纯观察、短反应、少折腾、无需刻意囤或顺着别人接话。
- 如果长度、开头或结尾明显扎堆，优先改整句节奏，不要机械加字或删字。
- 删除重复短语、悬空表达、广告口播和越界内容。

# 输出格式

只输出一个 JSON 对象。每个 item 同时保留策略字段和最终评论：

{"items":[{"strategy_id":"S01","response_mode":"direct_reaction","life_entry":"线上随眼看到","comment":"评论正文"}]}

items 必须恰好包含 10 个对象，strategy_id 按 S01 至 S10 排列。response_mode 只能使用上面的枚举；life_entry 用简短中文描述；comment 中不要出现策略标签。不要输出标题、编号、解释或 Markdown 代码块。


# 本轮共同控制条件

这是风格语料表示实验。为了只比较风格条件，S01-S10 的内容策略固定如下，不得互换；本节覆盖前文“自行确定回应模式 + 生活入口”的要求。

- S01：`direct_reaction`｜线上随眼看到｜只做一句即时反应，不展开后续动作。
- S02：`stock_observation`｜线上连续几次看到可买｜只说自己的库存观察，不写购买动作。
- S03：`personal_replenish`｜家里快喝完时补到｜只写自己补到一罐，不铺陈完整购买过程。
- S04：`less_hassle`｜以前需要反复确认｜重点是现在少折腾，不写具体抢购攻略。
- S05：`no_need_to_stock`｜别人提到要多囤｜表达不必刻意囤，按需要再买。
- S06：`casual_reply`｜回复别人说现在有货｜先承接对方，再补一个很小的个人观察。
- S07：`long_term_attention`｜长期使用会偶尔留意｜像老用户顺口说自己的观察习惯。
- S08：`before_after`｜前后状态对比｜写以前较难买、现在容易些，不用绝对化措辞。
- S09：`direct_reaction`｜家人或朋友带回消息｜只写听到消息后的个性反应，不追加行动链。
- S10：`stock_observation`｜日常逛商超时看到｜只写当下观察，不推断供货原因或趋势。

除当前策略卡明示的最小场景外，不补充人物关系、使用时长、渠道、数量、后续动作、供货原因或其他可核验经历。生活入口只写到足以成立，不扩成完整小故事。

输出中的 `response_mode` 和 `life_entry` 必须与对应策略卡一致。整组仍需横向检查，不能因为策略已固定就写成十个相同句架。


# A 组：无风格语料

本组不提供外部风格材料。严格执行共同控制条件，自由形成整组的评论区口气。
