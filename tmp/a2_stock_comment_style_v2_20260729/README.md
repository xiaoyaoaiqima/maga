# A2 有货评论风格语料实验 v2

## 目标

验证在“一次调用生成 10 条”的前提下，真人语料是否能提升整组实质差异和自然度，同时不带入新的身份、事实或动作。

本轮只做临时实验，不修改正式 Prompt、数据库资产或发布链路。

## 条件

- A / `core_only`：只有业务规则和固定内容策略。
- B / `shared_real_lines`：整组共享 10 条跨话题真人原句，不与 S01-S10 逐条绑定。
- C / `shared_surface_signatures`：使用与 B 同源的句面特征，不展示原句和原句语义。

三组都先执行 `common_control.md`。真人材料每条最多借一个兼容句面，不自然时可以完全不用。

## 重复与顺序

每个条件运行 3 次，每次一次调用生成 10 条，共 9 次调用、90 条评论。

1. round 1：A -> B -> C
2. round 2：B -> C -> A
3. round 3：C -> A -> B

模型参数固定为 `deepseek-v4-flash`、`temperature=0.9`、`max_tokens=1200`、thinking disabled。

内容不好不重抽；只有 JSON/schema 等技术失败才允许重试并留痕。

## 判断边界

- 主指标：整组是否像不同的人在说话。
- 同时看：自然顺口、直接可用数量、同骨架、新增事实或身份、策略漂移、真人原句近抄。
- 字符相似度只用于定位复核，不能代替真人 taste。
- 结果确认前不进入正式资产。
