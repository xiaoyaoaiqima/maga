# A2 有货评论风格语料 A/B/C 实验

## 目标

在同一个 A2“有货/库存稳定/容易买到”业务场景下，每组用一次模型调用生成 10 条评论，只比较风格语料的注入方式。

## 控制变量

- 模型：`deepseek-v4-flash`
- temperature：`0.9`
- max_tokens：`1200`
- 每组：一次调用、10 条
- 三组共用 `common_plan.md` 的固定内容策略
- 不修改正式资产，不接真实发布

## 实验组

- A：无外部风格样本。
- B：每条绑定一个完整真人示例。
- C：每条绑定一个由同源示例抽象出的风格纹理。

## 人工盲评

单条只标：`直接可用 / 局部改写 / 整句重写`；问题只选一个主因：`编造或逻辑 / 动作化 / 同骨架 / 语感不顺`。

整组只标：`通过 / 边缘 / 不通过`，并指出最相似的一对。
