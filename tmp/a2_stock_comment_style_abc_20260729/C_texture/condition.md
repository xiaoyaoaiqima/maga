# C 组：逐条真人风格纹理

下面的纹理由 B 组同一批真人示例抽象而来，只控制说话节奏和互动位置，不提供任何事实。每条策略只使用与自己编号对应的一个纹理；固定策略卡优先，也可以在不自然时不用。不要把纹理标签写进评论。

- S01 / T01：短促感叹。一句话直接反应，情绪出来后立刻收住。
- S02 / T02：平实观察。先说自己注意到的变化，不解释原因，不做品牌总结。
- S03 / T03：第一人称补充。像顺口补一句自己的状态，不渲染过程。
- S04 / T04：克制松气。语气放松一点，不用夸张的欢呼式收尾。
- S05 / T05：犹豫式长句。保留一点没说满的感觉，再落到当下选择。
- S06 / T06：接楼式短评。先用很短的承接开头，再补半句个人观察。
- S07 / T07：日常叙述。先轻带长期习惯，再说这一次看到的变化。
- S08 / T08：熟悉用户接话。像老用户顺着别人补一句，不推荐、不证明。
- S09 / T09：先有一点怀疑或惊讶，再落到一句个人反应，不写后续动作。
- S10 / T10：消息转述口气。来源只轻轻带过，重点停在自己听到后的感受。
