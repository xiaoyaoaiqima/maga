# A2 有货评论单次 10 条 Prompt 试跑

## 结论

- 3 次试跑均为单次模型调用，一次返回 10 条，30 条内无完全重复。
- 每次都覆盖 8 种回应模式，10 组“回应模式 + 生活入口”均不重复。
- 最大二元字符相似度分别为 `0.1163 / 0.1351 / 0.1212`，没有重复四字开头或结尾。
- 长度没有再作为配额目标；三组都自然出现了短句和中等长度评论，第一组还自然展开出 3 条较长评论。
- 当前主要剩余问题是个别用词和事实毛边，例如“门口海报写着有货”“买新鲜的更好”，需要继续由人工 taste 判断是否收窄，而不是重新增加长度配额。
