# 旺玥 Focused Pipeline 切流争议样本确认

## 使用方式

下面 4 条只用于人工定标。请为每条确认：

- `pass/watch`：单篇可用，不自动改写；
- `block_rewrite`：需要局部改写；
- `block_manual`：不适合自动补写，转人工。

人工确认前不修改 Judge Prompt，不切生产。

## 1. batch 498 item 7

标题：公园里自己爬上高梯，老母亲有点意外

正文：

> 那天在公园碰到邻居，随口说她家孩子最近老喊累。
> 我回想一下，我家这个三岁后每天跑跑跳跳，活动量越来越大。
> 当时正好在爬那个攀爬架，他蹭蹭蹭自己就上去了，我在下面仰着头看——以前总要我托一把的。
>
> 家里一直喝旺玥，营养够够的，怪不得长那么高。
> 当然每个孩子节奏不一样，我自己观察下来确实有这变化。

当前 Fluency：`semantic_discontinuity / block`

争议：Judge 认为没有旧状态参照，但原文已经写了“以前总要我托一把的”。初步判断更像误杀。

人工结论：`pass`。当前结果是误杀；真实 UGC 不要求逻辑完整，也不要求一定出现旧状态参照。

## 2. batch 514 item 5

标题：临时改计划也不慌

正文：

> 我们家小朋友吃饭是典型随缘型：上一顿风卷残云，下一顿筷子都懒得动。今天本来打算带他去外面吃顿好的，临时接到通知取消计划，只好回家凑合。果然，晚上正餐扒拉几口就喊饱。
>
> 还好家里常备着旺玥奶粉，大人正常冲一杯，钙铁锌和多种关键营养一块儿补充。一天两杯喝下来，至少基础营养这块不用我额外费心搭配了。

当前 Fluency：`semantic_discontinuity / block`

争议：Judge 要求解释奶粉如何“缓解食欲问题”，但原文实际表达的是正餐不稳定时做日常营养补充，并没有宣称改善食欲。初步判断更像过度审核。

人工结论：`pass`。当前结果是误杀；不需要额外解释旺玥如何改善食欲，原文只是在写日常营养安排。

## 3. batch 514 item 6

标题：一顿饭没吃好，泡杯旺玥补一补

正文：

> 昨天晚饭，孩子扒拉两口就说饱了。看着那碗几乎没动的菜，心里难免嘀咕：午饭在园里到底吃了多少？每次问也就回一句“吃了呀”，再问就说不清了。
>
> 后来给他泡了杯旺玥，就当把正餐里没吃够的营养补一补。看中它营养配得全，钙铁锌什么的一大堆，不用我再东补西补就行。
>
> 一顿饭吃得随缘，日常有这份安排，至少不会太慌。

当前 Temporal：`immediate_rescue_causality / block`

争议：现有立即补救金标主要针对打喷嚏、不舒服和疾病症状。需要人工确认“单顿饭没吃好后冲一杯做营养补充”是否属于正常日常安排。

人工结论：`pass`。普通一顿饭没吃好后冲泡旺玥补充营养，不属于立即补救。

## 4. batch 497 item 4

标题：晚上吃饭胃口也好

正文：

> 上周带孩子去爬山，搁以前回来准得瘫沙发上不想动。这回不一样，到家还能自己收拾书包，晚上吃饭胃口也好。
>
> 仔细想想就这两周开始喝的旺玥，每天一杯，大人冲好给他就行。营养搭得挺全，一杯里该有的都配好了，不用再额外操心补这补那。
>
> 日常状态肉眼可见稳了，不是那种马上见效的夸张，就是慢慢感受到的小变化。继续观察着吧。

目标帖子类型：`复购/长期使用`

Content Fit 两次相同输入结果：

- 第一次：`post_type_mismatch / block`，理由是只写“这两周开始喝”，没有复购、补货或长期使用关系；
- 第二次：`pass`，理由是两周使用后的自家反馈可视为长期使用。

争议：两周使用是否足以满足“复购/长期使用”帖子类型，还是应该只算普通使用反馈。

人工结论：`pass`。两周是复购/长期使用类型的最低成立线，不能低于两周；满两周不要求必须出现补货动作。
