## 审核边界

- 活动名可以出现，不是禁止写活动名。
- 不要写“这个活动叫×××”“活动名称是×××”“活动是会员升级”等专门说明活动是什么的句子。
- 直接自然地说“发现a2上了会员礼遇升级活动”。
- 这类问题标为 `light_fix`，只改活动引入句，不淘汰整篇文章。
