# 旺玥 Rewrite Quality 分歧样本详细 Review

## 怎么看

这四条只审核改写质量：改写后是否出现病句、语义断裂或无故丢失关键事实。是否真正消除了合规问题，仍由代码硬审或对应 Focused Judge 复审。

请重点判断两件事：

1. 被删内容是不是本次必须删除的目标问题；
2. 除目标问题外，有没有无故删掉值得保留的独立事实。

## 初步根因分层

| case | 初步判断 |
|---|---|
| WYR-007 | 更像上游误触发：两岁只是在回忆旧玩具，正文明确是满三岁后喝旺玥，并没有把旺玥和两岁使用关联起来。 |
| WYR-012 | 明确的改写质量问题：改写后重复“朋友也跟着换了”，应讨论 retry 严重度。 |
| WYR-013 | 更像旧审核口径残留：睡眠、精力、身高是否允许，本应由业务规则控制；若这些表达当前允许，就不该先触发 effect_scope_drift 改写。 |
| WYR-014 | 需要先对齐当前三岁以上孩子自行冲泡的口径；若已允许，child_self_brewing 目标本身就过期。 |

因此不能直接拿四条一起校准 Rewrite Quality Prompt。应先剔除上游目标错误或旧规则样本，再评估 grader。

## WYR-007｜两模型稳定 accept，候选 reject

- 来源：batch504 item4
- 改写来源：product_experience_phrase_guard
- 目标问题：wangyue_explicit_age_context
- 人工候选：reject / required_fact_loss
- 候选理由：删除了持续冲泡、孩子接受等独立使用事实，却没有删除真正命中的低龄回忆。

### 原文

**标题：** 翻出旧玩具，才发现

前几天整理储物间，翻出孩子两岁时玩的小滑梯。邻居随口说，你家小朋友最近跑跑跳跳，好像长高不少。

确实，满三岁后活动量大很多。这段时间家里一直喝旺玥，每天冲一杯，他自己端着喝得挺香。我看着那架小滑梯突然意识到，以前他爬上去都费劲，现在早就用不上了。

奶粉真不错，营养满满的感觉，孩子的变化就藏在这样的日常里。

### 改写后

**标题：** 翻出旧玩具，才发现

前几天整理储物间，翻出孩子两岁时玩的小滑梯。邻居随口说，你家小朋友最近跑跑跳跳，好像长高不少。

确实，满三岁后活动量大很多，这段时间家里一直喝旺玥。我看着那架小滑梯突然意识到，以前他爬上去都费劲，现在早就用不上了。

奶粉真不错，营养满满的感觉，孩子的变化就藏在这样的日常里。

### 实际变化

删除了：

> 每天冲一杯，他自己端着喝得挺香。

仍然保留：

> 孩子两岁时玩的小滑梯。

> 满三岁后活动量大很多。

### 模型三轮

- qwen-plus：accept / accept / accept
- qwen3-max：accept / accept / accept

两模型都认为“家里一直喝旺玥”已保留核心产品使用事实，“每天冲一杯、喝得挺香”只是可删细节，不构成关键事实损失。

### 需要人工拍板

- “每天冲一杯”和“孩子喝得香”是否必须视为独立关键使用事实？
- 本次目标是年龄上下文，但年龄内容完全没删；这种“没修到目标、反而删了别处”的候选，是否应由 Rewrite Quality reject，还是交给下一关判断目标问题仍存在？

## WYR-012｜Plus 稳定 accept，Max 稳定 reject，候选 retry

- 来源：batch449 item4
- 改写来源：product_experience_fluency_humanize
- 目标问题：ad_like_closure
- 人工候选：retry / semantic_discontinuity
- 候选理由：新增的收口重复“朋友也跟着换了”，局部删除重复即可修复。

### 原文

**标题：** 被朋友反向种草了

本来觉得3岁后奶粉随便选就行，直到朋友吐槽她家娃隔三差五请假，我才认真做功课。对比下来选了旺玥。现在喝了一阵，确实很少因为小状况缺课，朋友也跟着换了。选对奶粉，当妈的省心不少。

### 改写后

**标题：** 被朋友反向种草了

本来觉得3岁后奶粉随便选就行，直到朋友吐槽她家娃隔三差五请假，我才认真做功课。对比下来选了旺玥。现在喝了一阵，确实很少因为小状况缺课，朋友也跟着换了。现在孩子状态稳多了，朋友也跟着换了。

### 实际变化

删除了：

> 选对奶粉，当妈的省心不少。

新增了：

> 现在孩子状态稳多了，朋友也跟着换了。

导致“朋友也跟着换了”连续出现两次。

### 模型三轮

- qwen-plus：accept / accept / accept
- qwen3-max：reject / reject / reject

qwen-plus 三轮都漏掉了重复，认为新结尾只是自然补充。qwen3-max 三轮都识别出重复和指代问题，但将整条判为 reject，而不是可局部修复的 retry。

### 需要人工拍板

- 这种一句话内可删除的重复，是否固定标为 retry？
- “现在孩子状态稳多了”在这里是否存在指代不清，还是普通读者可以自然理解为自家孩子？

## WYR-013｜Plus 摇摆，Max 稳定 accept，候选 reject

- 来源：batch437 item14
- 改写来源：product_experience_compliance_cleanup
- 目标问题：effect_scope_drift
- 人工候选：reject / required_fact_loss
- 候选理由：为删除睡眠效果，一并删掉白天精力和身高等多个独立反馈，导致文章核心证据大面积丢失。

### 原文

**标题：** 翻到以前的记录本

整理书架时掉出一本旧记录本，里面记着娃刚上幼儿园时请假的日子。翻着翻着就想到现在，自从换了旺玥，这学期班里几轮身体不适都没落下她。当初就是冲着乳铁蛋白含量选的，没想到日常状态变化这么明显——晚上睡得沉，白天精力旺盛，连身高都窜了一截。小孩子的成长啊，真的藏在每天喝的那杯奶里。

### 改写后

**标题：** 翻到以前的记录本

整理书架时掉出一本旧记录本，里面记着娃刚上幼儿园时请假的日子。翻着翻着就想到现在，自从换了旺玥，这学期班里几轮身体不适都没落下她。当初就是冲着乳铁蛋白含量选的。小孩子的成长啊，真的藏在每天喝的那杯奶里。

### 实际变化

整段删除：

> 没想到日常状态变化这么明显——晚上睡得沉，白天精力旺盛，连身高都窜了一截。

一次删掉了三类反馈：睡眠、白天精力、身高。

### 模型三轮

- qwen-plus：reject / accept / reject
- qwen3-max：accept / accept / accept

qwen-plus 两轮认为三个具体反馈是关键事实，全部删除属于过度删减；另一轮认为它们都属于 effect_scope_drift 的目标删除范围。qwen3-max 三轮都把三类反馈整体视为目标问题，认为删除合理。

### 需要人工拍板

- 本次 effect_scope_drift 的准确目标范围是什么：只删“晚上睡得沉”，还是睡眠、精力、身高都要删？
- 如果只需删除其中一类效果，另外两类是否必须保留？
- Validator 是否需要接收明确的 target evidence，而不能只接收笼统 issue code？

## WYR-014｜Plus 稳定 accept，Max 单轮摇摆，候选 accept

- 来源：batch436 item16
- 改写来源：product_experience_compliance_cleanup
- 目标问题：child_self_brewing
- 人工候选：accept / none
- 候选理由：只删除孩子自行冲泡的目标句，其他观察和产品依据完整保留。

### 原文

**标题：** 终于找到对的配方

记录一下孩子最近的改变。换了旺玥之后，早起打喷嚏少了很多，整个人看着精神。当初做功课就是冲着它的乳铁蛋白含量。每天放学回来自己就会去倒水冲奶粉，这周末居然主动要求去游泳，以前可没这劲头。

### 改写后

**标题：** 终于找到对的配方

记录一下孩子最近的改变。换了旺玥之后，早起打喷嚏少了很多，整个人看着精神。当初做功课就是冲着它的乳铁蛋白含量。这周末居然主动要求去游泳，以前可没这劲头。

### 实际变化

只删除：

> 每天放学回来自己就会去倒水冲奶粉。

其他产品依据和状态反馈均保留。

### 模型三轮

- qwen-plus：accept / accept / accept
- qwen3-max：accept / accept / reject

qwen3-max 第三轮把“孩子自行冲泡”重新解释为关键产品使用事实，因此判 required_fact_loss；前两轮和 qwen-plus 都认为这正是目标问题，应允许删除。

### 需要人工拍板

- 当前旺玥边界是否仍然禁止三岁以上孩子自行冲泡？
- 如果业务已经允许三岁以上孩子自己冲泡，那么这条原始改写任务本身就不应再存在，不能只讨论改写是否 accept。

## 建议 Review 顺序

1. 先定 WYR-014 的真实业务边界，确认 child_self_brewing 是否仍是目标问题。
2. 再定 WYR-013 的目标删除范围，决定是否需要向 Validator 传 target evidence。
3. 再定 WYR-007 中“每天冲一杯、喝得香”是否属于必须保留的关键事实。
4. 最后定 WYR-012 的严重度：局部重复是 retry 还是 reject。
