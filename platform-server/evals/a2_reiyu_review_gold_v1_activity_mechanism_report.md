# a2 礼遇活动机制审核金标 v1

## 状态

`activity_mechanism_v1` 已于 2026-07-20 完成人工确认。

## 集罐奖品标准

- 3罐：小车车。
- 6罐：自行车。
- 12罐：奶粉。
- 18罐：婴儿车。

## 放行边界

- 旅游基金大奖可以自然写成“新西兰旅游”或“新西兰旅游大奖”，金额正确即可，不要求奖品名称逐字统一。
- “买完奶粉扫罐码集罐”可以出现。
- “正好要补货”“又该囤货”属于未来购买意向，可以出现。
- “活动期间买完后扫罐码累计”明确属于活动期内新购，可以出现。
- 检测语境里的“扫罐码能看到信息”按扫罐底码查询理解，可以出现。
- 奶粉使用“吃”“吃完”等口语表达可以出现。
- 同篇可以同时写抽奖和集罐，明确标明各自奖品归属当然可以。
- 先列玩法、再统一罗列奖品也可以；没有明确写错归属时，不要求逐项拆分。
- 正确档位后可以泛提其他档位奖品。
- 6罐换自行车后，把这辆自行车口语称为“小车车”可以出现。
- 可以写已经领到小听、老客回归礼、会员权益，也可以写已经完成确定性的集罐兑换。
- 小听粉属于老客回归礼；全文没有老客身份时，只写“会员升级送小听粉”会省略领取资格，需要轻修。前文已经写明家里一直喝、老粉或老用户时，后文说“还能领小听粉”可以通过。

## 轻修边界

- “12罐到手13罐，还有小车车送”容易被理解为12罐档位额外赠送小车车，需要拆开不同档位表达。
- “奶粉喝完了把罐子存着”没有明确证明活动前旧罐可参加，不按资格硬错处理；改成直接说参加集罐。

## 直接删除边界

- 把小车车、自行车、奶粉或婴儿车等集罐奖品写成积分兑换。
- 把旅游基金、金手链或夏凉被等抽奖奖品写成积分兑换。
- 把集罐写成兑换积分。
- 积分素材没有提供具体礼品时，自行编造“小玩具、绘本、奶粉周边”等积分礼品。
- 多重福利素材没有提供具体机制时，自行编造“积分翻倍、双倍积分、专属赠品”等福利。
- 暗示活动开始前购买或家中原有的旧罐可以参加本次活动。
- 家庭现有库存与集罐、扫码或兑换跨句连接时，同样按旧罐资格错误直接删除。
- 明确写错罐数与奖品的对应关系。
- 自称已经抽中或拿到旅游基金、金手链、夏凉被等抽奖奖品。

## 本轮新增金标

- `A2RY-AM-012`：`pass`，集罐兑换属于确定性权益，可写已经拿到。
- `A2RY-AM-013`：`reject`，积分兑换夏凉被和金手链等抽奖奖品。
- `A2RY-AM-014`：`reject`，集罐兑换积分。
- `A2RY-AM-015`：`reject`，“家里正好存了几个罐子”隐含旧罐参加。
- `A2RY-AM-016`：`light_fix`，只出现存空罐措辞时局部改写，不升级为旧罐硬错。
- `A2RY-AM-017`：`reject`，积分素材未提供具体礼品却自行编造礼品。
- `A2RY-AM-018`：`reject`，“家里刚囤了一箱，娃催我扫码”把家庭现有库存与本次集罐资格连接。
- `A2RY-AM-019`：`pass`，“又该补货”并明确活动期间购买后累计，属于新购参加活动。
- `A2RY-AM-020`：`pass`，检测语境里的“扫罐码能看到信息”按扫罐底码查询理解。
- `A2RY-AM-021`：`reject`，自称已经抽中抽奖奖品。
- `A2RY-AM-022`：`light_fix`，标题“会员升级送小听粉”省略老客回归资格。
- `A2RY-AM-023`：`reject`，多重福利素材未提供具体内容，却自行编造积分翻倍和专属赠品。
- `A2RY-AM-024`：`pass`，前文已经表明长期饮用的老客身份，后文可直接说还能领小听粉。
