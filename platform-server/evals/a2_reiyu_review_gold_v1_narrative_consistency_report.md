# a2 礼遇活动叙事一致性审核金标 v1

## 状态

`narrative_consistency_v1` 已完成人工确认。当前覆盖老客购买意愿歧义、历史转奶叙述放行和标题正文使用时长冲突。

## 审核边界

- 同一篇文章中的购买、使用和复购身份必须前后一致。
- 后文写明“喝了几个月”“继续回购”等经历时，前文应保持已购老客口吻。
- “本来就一直想囤他们家”与后文长期使用经历存在歧义，标为 `light_fix`。
- 最小修改是删除“想”，改成“本来就一直囤他们家”；文章不需要整篇淘汰。
- 不把“想”设为通用禁词，只在它确实造成已购/未购身份冲突时标记。
- “我家本来就喝a2至初”是当前状态，“之前换a2后”是历史经历，两者可以同时成立，应当通过。
- “我家一直喝这个”通常表示转奶后持续饮用，后文回顾“宝宝喝这个转奶挺顺利”也应当通过；只有明确写“从出生一直喝、从来没换过”后又写转奶才冲突。
- 标题写喝了两年、正文写喝了大半年属于明确时长冲突，但只需统一一处，标为 `light_fix`。

## 当前金标

- `A2RY-NC-001`：`light_fix`，原始歧义样本。
- `A2RY-NC-002`：`pass`，删除“想”后的通过样本。
- `A2RY-NC-003`：`pass`，当前用户回顾以前转奶经历，不误判为时序冲突。
- `A2RY-NC-004`：`light_fix`，标题和正文的使用时长明显不一致。
- `A2RY-NC-005`：`pass`，长期饮用与回顾最初转奶经历可以同时成立。

## 后续批量审核口径

批量审核时逐篇输出：样本标识、标签、命中原文、理由和最小修改建议。当前这份金标只覆盖购买、使用、复购身份和使用时长一致性，不自动扩张到活动机制、奖品归属、产品宣称或文风审核。
