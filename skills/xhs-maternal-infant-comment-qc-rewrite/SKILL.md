# 小红书母婴评论质检重写

用于把评论批量产出从“看起来像评论”推进到“可过运营/品牌审核”。默认场景是源悦奶粉评论区短评，输入通常是 `文章池导出_*.xlsx`、评论 CSV、`评论切角_子关键词导出.csv`、审核范本或已审核表。

## 核心原则

- 先质检，后重写；先按审核范本和脚本定位问题，不凭感觉泛评。
- 生成侧默认不用 `挺/稳/顺` 做评价收尾。质检时少量真实口语可人工放行，但 `挺稳、挺顺、挺安稳、体质稳、曲线稳、便便顺、拉屎顺、喝得顺` 这类一律优先打回。
- 已购/喝后/转后不能出现产品后负面结果，例如 `拉肚子、便便变绿、屁多、冲不开、没啥反应、水解正在试`。未购可以问购买前痛点，但 0603 后 `粑粑干` 要改成 `大便比较干燥`。
- 源悦必须是最终在喝、准备买、正在问的对象。竞品只能作为来源，例如 `能恩转源悦`，不能写成 `转能恩/水解刚试/小罐水解先试`。
- 重写不要追求更漂亮，要更像评论区：短一点、具体一点、少总结词、少完整解释链。

## 必读参考

如果文件存在，先读这些文件再判断：

- `批量生成/源悦-评论 - 评论0602-审核范本.csv`：看不 OK 原因和运营改写方向。
- `批量生成/源悦-评论 - 评论0602-已审核.csv`：看通过样例和仍需注意的审核意见。
- `scripts/check_comment_corpus_reference_consistency.py`：优先运行它做基础风险和同质化扫描。
- `关键词语料/评论切角_子关键词导出.csv`：需要回溯源语料时再看。

常用命令：

```bash
python scripts/check_comment_corpus_reference_consistency.py --article-pool-xlsx '批量生成/文章池导出_YYYY-MM-DD (N).xlsx' --homogeneity-report --max-items 150
```

## 质检流程

1. 解析产出文件：确认总行数、正文列、`上下文变量(context_list)`、评论切角分布。
2. 跑监测脚本：记录高风险、`挺/稳/顺/顺手/儿保` 等高频观察。
3. 对照审核范本：把脚本没抓到但运营会反感的表达补进问题清单。
4. 按问题类型归类，不要只逐条碎评。
5. 如果用户要求重写，先清高风险，再做去模板化复扫；如果用户要求改文件，直接写回同一表或指定 CSV，并保留原字段。

## 改写版产出流程

用户说“搞一个改写版本”“直接改文件”时：

1. 不覆盖原始 `文章池导出_*.xlsx`，优先另存为 `原文件名-质检改写版.xlsx`。
2. 保留工作簿、工作表、列结构和行号，只改 `正文` 列，除非用户明确要求新增审核列。
3. 第一轮清高风险：处理 `挺/稳/顺` 安全总结、产品后负面结果、源悦对象错误、短周期下结论、不自然场景。
4. 跑监测脚本，要求 `high=0`、`medium=0`；若不为 0，继续改正文。
5. 脚本通过后继续看 `soft_template` / `soft_template_pattern` 观察。不要因为高风险清零就结束，要检查是否把问题替换成新的高频安全话术。
6. 必要时做第三轮去模板化微调，再跑脚本和自扫，最后告诉用户新文件路径、改了哪些行、校验结果。

第二轮自扫重点：

- `费不费劲、娃肯喝、能喝完、没怎么、基本每天、不太、差不多每天、能接受、接上、这阵子、最近、没抗拒`
- `小罐` 可因过敏/转奶/试用切角保留，但同批不要所有过敏相关都写成同一套句式；0603 反馈后，过敏相关不要提 `旧奶粉/兑着旧奶粉/从旧奶粉转过来`。

去模板化时不要一换一制造新模板：

- 0603 后不要把 `费不费劲` 全部替换成 `会不会用力/有没有憋着/有没有憋劲`，这些反而被运营打过；可轮换 `拉屎不费劲了`、`便便规律，基本一天一次`、`干不干`、`拉粑粑基本每天1次`。
- `娃肯喝/能喝完` 可以拆成 `很喜欢`、`爱喝`、`还挺爱喝`、`准备再囤一点`、`奶量从X到Y`；不要写 `奶瓶里不怎么剩`。
- `没怎么/不太` 高了就改成更具体的小事实，例如 `少哼唧`、`没鼓起来`、`不用太使劲`、`没掉下来`。
- `能接受` 高了就拆成 `性价比高`、`很划算`、`准备再囤一点`、`很喜欢`；0603 后不要写 `预算里/配这个价`。

## 0603 运营反馈新增口径

- 消化吸收：`肚子没鼓` 容易被认为不准确，优先写 `没有胀气`、`喝完奶肚子不鼓了`、`不哼哼唧唧了`、`没有不舒服`。不要为了避模板写成奇怪句子。
- 性价比：`预算里`、`配这个价`、`配方和价格我都看过`、`奶瓶里不怎么剩` 都打回；优先写 `性价比高`、`很划算`、`准备再囤一点`、`很喜欢`。
- 生长发育：不能只写 `再称/再看/下次体检/体重没掉/奶量接上`，要有具体身高体重数据或对源悦的认可，例如奶量、爱喝、体检身高在中上。
- 便便问题：指代要清楚，不能只写 `每天基本有/每天差不多能看到一次`；运营更接受 `便便规律，基本一天一次`、`拉粑粑基本每天1次`、`拉屎不费劲了`。
- 过敏相关：不要提 `旧奶粉`，改成 `源悦小罐先试`、`前几顿先少量`、`按顿加着看`。严重情况仍建议问医生。
- 未购痛点：`粑粑干` 改成 `大便比较干燥`；`总吐` 改成 `总吐奶`；`嗯嗯` 可以换成 `拉屎/拉💩/拉臭臭/拉粑粑`。
- 奶量补充：数字要合常理，避免 `三顿150ml` 这种容易被理解成一顿不到常识量的写法；可以直接加 `还挺爱喝`。
- 口语称呼：`我崽` 被打过，优先写 `我家娃/我家宝宝`。

## 高优先级打回项

### 1. 挺/稳/顺安全总结

打回：

- `挺稳、挺顺、挺安稳、挺适应、挺满意、还挺认、挺对味`
- `体质稳、曲线稳、奶量稳、便便顺、拉屎顺、喝得顺、转奶顺利`
- `还行、还可以` 如果缺少具体事实，也按抽象评价处理。

优先改成：

- 便便：`便便规律，基本一天一次`、`拉粑粑基本每天1次`、`拉屎不费劲了`
- 奶量：`之前150ml喝不完，现在能喝到180/200ml`
- 过敏/转奶：`源悦小罐先试`、`前几顿先少量`、`按顿加着看`
- 性价比：`性价比高`、`很划算`、`准备再囤一点`

### 2. 时间太短就下结论

打回：

- `第一顿喝得挺顺`
- `喝了两三天便便规律/拉屎顺了`
- `转奶第三周臭臭一直正常`
- `刚换几天就适应了`

优先改成：

- `前几顿先少量混着来`
- `刚开小罐，先看喝奶接受度`
- `这几天只看奶量和拉屎费不费劲`
- `喝完一罐再看`

### 3. 不自然场景和过度编细节

打回：

- `拉完就去玩玩具`
- `出去玩回来没喊累`
- `白天能多玩半小时`
- `自己抱着喝完还舔嘴`
- `拉完马上去玩/疯玩/精神头明显变好`

优先改成：

- `拉完没怎么闹`
- `准备再囤一点`
- `白天吃睡玩都照常`
- `抱起来感觉沉了点`

### 4. 生长发育功效感

打回：

- `喝后长高/长肉明显`
- `曲线稳、体重稳着涨`
- `个子窜了、小腿结实了`
- `精神好所以发育好`

优先改成：

- `+1，我们也是个子涨得快`
- `体检身高在中上`
- `10个月20斤来报道`
- `衣服好像短了点`
- `抱起来比上个月沉了点`
- `奶量没掉还爱喝`

### 5. 消化吸收功效链

可以写口语化前后差异，但不要写成治疗或强功效。

打回：

- `肚子舒服多了`
- `拍完嗝顺了`
- `吐奶少多了`
- `肚肚稳当多了`
- `喝完挺轻松`

优先改成：

- `喝源悦不胀气是真的`
- `以前那顿容易哼唧，这阵子少些`
- `喝完奶肚子不鼓了`
- `转奶按顿来，前几天别急着加量`

### 6. 负面因素和产品方向

打回：

- 已购后写 `拉肚子、便便变绿、屁多、颜色深、有颗粒、冲不开、没啥反应`
- `水解刚试、小罐水解先试、转能恩、试能恩`
- 过敏相关写 `旧奶粉/兑着旧奶粉/从旧奶粉转过来`
- `过敏宝换奶` 如果写成自家正在试某产品后的负面结果

优先改成：

- `严重的先问医生`
- `源悦小罐先试，前几顿少量来`
- `买源悦小罐先试口感/接受度`

### 7. 高频模板词

批次里超过阈值要提示：

- `挺`：100 条尽量不超过 5 条。
- `稳`、`顺`：看总量和语境，身体/喂养状态后接这些词要重点打回。
- `顺手`：规则和正文都尽量不用，改成 `评论区接话、补问、简单问一句、轻轻留一句`。
- `儿保`：生长发育可少量出现，别高频写成 `等儿保/看儿保数据`。
- 脚本未报错但批次高频的安全词也要降，例如 `费不费劲、娃肯喝、能喝完、没怎么、基本每天、不太、能接受`；这类词不是禁用词，但一批里重复会显得像同一个人写的。

## 重写格式

用户要“列问题”时：

```text
总体判断：这批主要卡在……

高优先级打回：
row X | 切角 | 原文
问题：……
建议：……
```

用户要“直接给点点审查”时：

```text
原文：……
建议改成：……
原因：……
```

用户要“直接改文件”时：

- 保留原表列结构。
- 只改正文列，除非用户要求新增审核列。
- 改完后再跑监测脚本，高风险必须清零；同质化观察要说明是否保留。
- 脚本高风险清零后，还要看 soft template 观察；如果出现 3 次以上的同尾句或 5 次以上的同表达，优先拆成不同事实说法。

## 重写示例

```text
原文：便便挺顺的，拉完就去玩玩具了
建议：基本每天都有，拉屎没怎么费劲

原文：买了源悦小罐先试，第一顿喝得挺顺的
建议：买了源悦小罐先试，第一顿没抗拒

原文：喝了两年体质确实稳
建议：喝了大半年了，一直喝的源悦

原文：体检说曲线稳，身高一直没掉队
建议：体检身高一直在中上，接着喝

原文：刚喝几天，拉屎倒是顺了
建议：刚喝几天，我先看拉屎费不费劲
```

## 最后校验

完成重写或规则修改后，至少检查：

- 产品对象是否仍是源悦。
- 已购后是否有负面结果。
- 是否仍有 `挺稳/挺顺/体质稳/便便顺/拉屎顺`。
- 是否把短周期写成结论。
- 是否出现不自然生活场景。
- 是否有重复句式或高频词，尤其是清掉风险词后新冒出来的安全模板词。
- 是否保留原始文件，并输出独立改写版文件路径。
