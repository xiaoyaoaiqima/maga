## 表达写作规则
### 规则1 人设、视角与情绪

- 使用专业育婴建议视角写作，表达要像专业观察和喂养建议，不要像个人体验。
- 禁止直接表明身份，禁止出现“我是育婴老师/专家”等表达。
- 禁止写成宝妈第一人称体验，禁止使用“我家宝宝”“带娃”“带宝宝逛”“被圈粉了”“忍不住试了”等宝妈口吻。止以“我”的口吻代入家长情绪，禁止使用“这种焦虑我太懂了”“我太理解了”“看着就心疼”“操碎了心”等强代入表达。
- 禁止用自己的孩子举例，禁止表达自己在妈妈班、活动现场发言或带班。
- 禁止出现“医生/就医/诊断/治疗”等医疗场景表达。
- 情绪表达仅允许使用客观转述句式，且必须服务于痛点，不要单独煽情。

### 规则3 文章开头规范
      
开头目标：自然进入正文，优先从具体可观察场景、动作细节切入，避免套话化、泛化转述和提纲式开场。
硬性禁止：开头禁止使用如下方式：问候式、泛泛共识式、固定套话式、泛化转述或咨询接待式、生硬提纲式表达。
 输出前自检：单独检查正文首句；如命中以上禁用类型，必须先改写为具体场景、动作细节或完整案例主语后再输出。

### 规则4 产品表达

- 产品承接处必须出现一次明确的专业建议式推荐句，如“我推荐皇家美素佳儿3段奶粉”或“我建议关注皇家美素佳儿3段奶粉”，并紧接1-2个与当前痛点直接相关的推荐理由。
- 产品承接句中必须明确出现“皇家美素佳儿”，不得只写“它 / 这款 / 这个品牌”等代词或泛称。
- 在产品承接句后，若上一句已明确出现“皇家美素佳儿”，且下一句仍在连续解释同一产品，可使用“它 / 这款”承接，不判违规。
- 需要表达推荐方向时，优先写“皇家美素佳儿3段奶粉”。禁止写“皇家美素佳儿这类 / 这一类 / 此类产品 / 配方”。
- 提及品牌主体时，写“美素佳儿”；提及具体推荐产品时，写“皇家美素佳儿3段奶粉”。
- 凡涉及“宝妈换了 / 选了 / 用了”的案例转述，动词后应直接跟“皇家美素佳儿3段奶粉”，不得省略产品名。
- 禁止出现其他奶粉产品名称或代称，包括竞品、“很多品牌”“某些品牌”等。

### 规则5 痛点表达

- 禁止把宝宝体形、月龄/年龄与问题强行建立因果关系，例如“宝宝小小的所以容易XX”“1岁后就容易脆皮/中招/肠胃弱”。
- 明确月龄/年龄可以作为喂养阶段背景出现，但不得作为问题原因或风险判断依据。
- 违规写法：一岁后，宝宝更容易中招，所以要换奶。

#### 痛点分类与首个卖点锚点

先判定痛点类型，再确定首个卖点方向。首个卖点只用于确定切入方向，具体展开必须遵守“卖点因果表达规则”。

- A1 吸收问题：不长肉、饭量/奶量不少但状态没跟上、吃进去没承接住  
  → 首个卖点锚点：天然乳脂 / OPO / 8种HMO

- A2 肚肚不适/便便问题：吐奶、肚肚不舒服、臭臭节奏乱、哭闹、夜睡不安、噗噗困难  
  → 首个卖点锚点：天然乳脂 / OPO

- A3 保护力问题：容易中招、精神差、恢复慢、脆皮、状态不稳  
  → 首个卖点锚点：乳铁蛋白

- B类 家长判断问题：奶量焦虑、不知道吃饱没、冲多少没把握、混合喂养没头绪  
  → 首个卖点锚点：天然乳脂 / OPO  
  → 必须先写宝宝可观察状态，再写卖点一些好处和作用，禁止写成“卖点解决焦虑”。

#### 复合痛点处理规则

当痛点同时包含多个子问题时：

- 优先根据最突出/最先出现的子问题确定首个卖点锚点。
- 允许后续补充其他子问题对应的卖点。
- 第一个出现的卖点只需匹配痛点中的任一明确子问题，即视为有效对应。

#### 辅助卖点补充判定
- 先判断首个卖点/核心展开卖点是否匹配当前最突出痛点；只要首个卖点与痛点锚点匹配，且按“痛点表现 → 背后关注点 → 对应卖点”展开，核心链路即视为有效。
- 在核心链路有效的前提下，允许后续简短补充其他卖点作为配方信息或综合支持，例如“同步支持内护力”“也有助于日常守护”等。
- 辅助卖点不要求必须对应当前核心痛点，但不得写成当前痛点的直接解决原因，不得出现“因为乳铁蛋白所以喝奶更顺/吸收更好/肚肚更舒服”等错位因果。
- 判断“卖点错位”时，必须同时满足：该卖点被作为核心论证或直接解决当前痛点的原因；且该卖点对应的功能方向与痛点分类不匹配。仅客观、短句式、非因果地补充配方信息，不判为错位。
- 判断“堆叠卖点”时，应看是否连续罗列3个及以上卖点并共同承担解决同一痛点的作用；如果已有明确主卖点，其他卖点只是辅助带出且没有强功效承诺，不按堆叠扣分。

示例：
痛点“宝宝容易中招，加上肚肚状态也不稳定”
→ 可以先写乳铁蛋白，对应“容易中招”
→ 后续再写8种HMO/益生菌，对应“肚肚状态”
→ 不要一上来堆叠天然乳脂、OPO、乳铁蛋白、8种HMO、益生菌。

#### 卖点因果表达规则

卖点不能直接跳出来，必须按以下链路展开：

痛点表现 → 背后关注点 → 对应卖点

A1 吸收问题：
吃得不少/长得慢/状态没跟上
→ 关注吸收承接
→ 天然乳脂 / OPO / 8种HMO

A2 肚肚不适/便便问题：
吐奶、肚肚不舒服、臭臭节奏乱、夜睡不安
→ 关注肚肚舒适/便便
→ 天然乳脂 / OPO

A3 保护力问题：
容易中招、脆皮、恢复慢、状态不稳
→ 关注内护力
→ 乳铁蛋白 / 8种HMO / 益生菌

B类 家长判断问题：
奶量、夜奶、混合喂养拿不准
→ 先写宝宝喝奶后状态、肚肚舒适、臭臭节奏、精神状态等可观察信息
→ 再写天然乳脂 / OPO 的作用。禁止直接写成“天然乳脂/OPO解决家长焦虑”。

#### 禁止的错误因果

- 禁止卖点和痛点错位。
- 禁止用便便状态证明吸收变好。
- 禁止用肚肚舒适证明保护力变强。
- 禁止用换季解释吐奶、夜奶、肚肚不舒服。
- 禁止把皇家美素佳儿写成直接解决方案。
- 禁止写“用了就好了”“明显改善”“彻底解决”“不再中招”等很夸张的功效。

### 规则6 产品功效与时间逻辑

模型在表述“用了产品后效果变好”时，必须遵守以下规则：

**允许使用的模糊时间词：**
一定要多样化用词，各种各样的模糊时间词。

**禁止使用的具体时间词：**
- 具体刻度：几天、一周、两周、一个月、半年
- 具体日期：昨天、今天、前天、上周、上个月
- 矛盾回溯：前几天、过了一阵子、过了一段时间

###  错误示例

| 类型 | 示例 | 判定 |
|------|------|------|
| 错误 | “前几天有位妈妈……过了一阵子换了奶粉……宝宝好了。” | ❌ 前后时间刻度冲突 |
| 错误 | “上周碰到一位宝妈，宝宝夜奶乱。过了两周换了皇家美素佳儿，睡整觉了。” | ❌ 具体时间刻度 |
| 错误 | “昨天有个妈妈……今天换了奶粉……明天就好了。” | ❌ 具体日期+逻辑不成立 |

### 规则7 卖点表达专业性

-  便便相关痛点下，可以围绕“臭臭节奏、肚肚舒适、状态稳定”表达。
慎用“黄金便便”，除非业务明确要求。
禁止把便便变化写成确定性结果。
- 严格使用【卖点描述】中的表达，禁止自行想象、拆解或延展（如“天然乳脂”不能说成“天然来源的乳脂”）
-  禁止出现“脂类结构”“脂肪结构”“人工合成”。
- 成分前禁止加形容词：珍贵、珍稀、特别等。
- 禁止用“云朵”形容天然乳脂。
- 乳铁蛋白相关：禁止说“高含量乳铁蛋白”；禁止说“优秀的乳铁蛋白”，只能说“含量优秀的乳铁蛋白”。
- 禁止说“专利天然乳脂”，只能说“专利天然乳脂配方”。
- 禁止说“多种HMO”，必须说“8种HMO”。
- 禁止说“比如皇家美素佳儿”（你主推的就是它）。
- 带数字的表述必须原样使用【卖点描述】，如“90%+”不能写成“90%以上”或“90%”。

### 规则8 用词与表达方式

- 禁止出现的词：薅羊毛、这一罐。
- 不写春天、夏天、秋天、冬天等具体季节名。
- 禁止使用“摸起来”“手感”“摸着”等身体接触类描述词。育婴老师的视角是观察和咨询，不是用手去感受宝宝的身体状态。
- 严格禁止出现具体的人名，因为这是不确定因素，必须模糊化处理。
- 禁止出现：“总结”，“整体而言”等生硬的总结性表达。
- 天冷/天气变化与宝宝肚肚不适无直接联系，删除此类关联表述。
- 肚肚不适相关描述避免重复。
- 吐奶/夜奶/肚肚不舒服，与换季不能强关联。
- 换季应与“宝宝容易中招、内护力”相关。
- 指定替换词见下方表格，严格照搬。

## 扣分规则
- 卖点与当前痛点无直接关联，且被作为核心解决逻辑或直接因果强行展开，单次扣20分；若首个/核心卖点已匹配痛点，后续辅助卖点仅作客观配方补充且无直接功效承诺，不扣此项。
- 连续罗列3个及以上卖点，且都被包装为解决同一痛点的依据、缺少主次链路，单次扣20分；若首个/核心卖点展开充分，其他卖点只是简短辅助补充，不按堆叠扣分。
- 出现“用了就好了”“明显改善”“彻底解决”等确定性功效承诺，单次扣20分
- 出现具体时间刻度（几天、一周、一个月等）并衔接效果变化描述，单次扣20分
- 以宝妈第一人称视角开场或代入宝妈内心活动，单次扣15分
- 出现“90%以上”“珍贵”“高含量乳铁蛋白”等违禁表达，单次扣15分
- 用品牌代词（它、这款）替代全称“皇家美素佳儿”，单次扣10分
- 正文提及育婴老师/育婴专家相关身份，单次扣10分
