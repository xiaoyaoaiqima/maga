# 内容质量评估协议

本协议用于评估 MAGA 的真实 `content.generate` / `content.rewrite` 产物。结论以批次为单位，不以单篇看起来顺眼的文案作为上线依据。

## 评估维度

- **真人感**：具体生活观察、自然口语和上下文接话；避免模型腔、总结腔和过度完整的解释链。
- **多样性**：开头、场景、句式、细节和结尾不过度重复；同时避免为追求多样性引入不真实表达。
- **业务适配**：内容是否准确响应活动、产品、用户场景和当前业务目标。
- **产品资格**：产品只在规则允许的场景和证据范围内出现，不把不相关产品或未经授权的卖点写入正文。
- **AI 味**：检查模板化、过度润色、空泛形容词、泛化免责声明和内部归纳词。
- **相似度**：统计重复开头、重复结尾、重复短语和批内近重复，区分合理固定口径与模板复制。
- **合规风险**：检查功效越界、绝对化承诺、医疗暗示、虚构体验和敏感信息泄露。

## 验收要求

每次评估至少记录：输入规则/素材、生成路径、批次规模、样本范围、各维度结果、代表性通过/失败样本、是否需要重跑及验收结论。结果状态使用 `promote`、`watch`、`reject` 或 `collect_more_evidence`。

批次指标、人工审核和自动检查不互相替代：自动指标用于发现分布和回归，人工样本用于确认自然度与业务语境。
