# 小红书口语化词典

> 让文字"像人写的"而不是"像 AI 写的"。
> 在生文时，凡是 AI 套话都对照这张表替换。

---

## 称呼

| 不要 | 要 |
|---|---|
| 各位读者 / 大家 | 姐妹们 / 家人们 / 宝妈们 |
| 您 | 你 |
| 用户 / 消费者 | 我们 / 大伙儿 |

---

## 开篇 — 严格禁用万能开场

❌ 禁用列表（来自 common_sense AE 规则）：
- 时间类：最近 / 今天 / 近期 / 近日 / 现阶段 / 目前 / 当下 / 近来
- 万能套话：大家好 / 各位 / 相信很多人 / 想必大家都知道 / 说起 XX
- AI 套话：在快节奏的现代生活中 / 在如今 / 随着 X 的发展

✅ 推荐开场：
- 反问钩子："姐妹们有没有遇到这种情况..."
- 场景代入："凌晨 3 点喂奶时..."
- 反差开场："本来以为..."
- 干货预告："给宝妈整理了 5 个..."

---

## 痛点表述 — 转述而非自述

❌ 不要："我家宝宝之前不爱喝奶..."（自我中心）

✅ 要：
- "宝妈跟我说她家宝宝..."
- "我遇到很多宝妈这样反馈..."
- "前两天看群里有姐妹问..."

---

## 卖点措辞软化

| AI 感强 | 口语化 |
|---|---|
| 该产品具备 XX 功能 | 它真的能 XX |
| 显著提升 | 明显感觉 / 用了一段时间能看出来 |
| 针对 XX 痛点 | 我家宝宝之前那种 XX 情况 |
| 独家配方 | 配方里有 XX |
| 经过精心研发 | 听说研发了好几年 |
| 性价比高 | 算下来不贵 / 比之前那款省了点 |

## 情绪词（小红书味）

- 正向：绝绝子 / 真香 / 爱住 / yyds 慎用 / 真的会爱 / 救命 / 醒醒
- 反向：踩坑 / 翻车 / 雷死了（注意广告法限制）
- 共鸣：谁懂啊 / 真的 / 太了 / 诶诶诶

## AI 味检测自查清单

写完后回读，命中以下任意一条 → 重写：

- 出现"在...的时代/背景下"
- 出现"我们都知道" / "众所周知"
- 出现连续 3 个并列短语（"高品质、高营养、高安全"）
- 出现"本产品" / "该产品" / "此款"
- 段落开头都是同一个句式
- emoji 多于 5 个或扎堆出现
- 整篇没有"我/我们/姐妹"等口语主语
