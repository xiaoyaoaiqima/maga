# 小红书爆款笔记 — 风格 / 结构 / 模板

> 这是 GE（生文官）自己的私房风格库。AE 的指令是约束，这里是**可参考的母版**。
> 当 spec 没有强制结构时，从这里挑一个匹配 brief_type / 字数 / 调性 的模板。

---

## 标题钩子模板（前 7 字）

| 钩子类型 | 模板 | 例子 |
|---|---|---|
| 痛点反问 | "XX 真的有用吗？" | "转奶粉真的会拉肚子吗？" |
| 数字盘点 | "X 个 / N 大..." | "5 款待产包对比，新手妈妈不踩坑" |
| 反差/真香 | "本来不信...直到..." | "本来不信奶粉广告，直到换了 a2" |
| 情绪共鸣 | "姐妹们救救/家人们谁懂" | "家人们谁懂转奶娃娃的崩溃" |
| 场景代入 | 时间+地点+动作 | "凌晨 3 点喂奶，我才发现..." |
| 干货承诺 | "全网最全/保姆级" | "保姆级新生儿待产包清单" |
| 喊话式 | "宝妈/姐妹/X 月龄妈妈看过来" | "敏宝妈妈一定要看！" |

emoji 用法：
- 标题首位 / 末位放 1 个（情绪→💛✨🥹；干货→💡📒；惊喜→🌟🎀）
- 中间不要塞 emoji

## 正文骨架模板

### A. 痛点-解决方案-种草型（150-250 字）

```
[1] 钩子段（1-2 句）
   抛痛点 / 真实场景 / 反差开场

[2] 痛点展开（1 段）
   姐妹们应该都遇到过... 我家宝宝之前...
   （此处避免说自己孩子状况，要转述视角）

[3] 转折 + 引出产品（1 段）
   后来朋友推荐了 XX / 看到一个测评 / 偶然发现
   （自然，不硬广）

[4] 产品事实+卖点（1-2 段，每段 1 个卖点）
   - core_ingredient：a2蛋白
   - 体感：宝宝接受度高、不闹

[5] 收尾互动（1 句）
   姐妹们用过的可以评论交流哦~

#hashtag1 #hashtag2 ... (5-15 个)
```

### B. 干货价值型（保姆级 / 知识科普）

```
[1] 钩子：数字承诺 / 干货预告
   "宝妈必备！5 个转奶不拉肚的小技巧"

[2] 总起一句：本文要解决什么

[3] 分点展开（每点 1 段，3-5 段）
   1️⃣ 第一点 + 解释
   2️⃣ 第二点 + 解释
   ...

[4] 收尾：行动号召
   "收藏起来慢慢看，姐妹们还有问题评论区聊"
```

### C. 真实路人 UGC 型

```
[1] 流水账开头：今天/最近发生什么
[2] 痛点：遇到了什么困难
[3] 解决：尝试了什么 / 用了什么
[4] 反馈：现在的状态
[5] 推荐：要不要也试试
```

### D. 活动预告 / 分享型（offline_mama_class）

适用：下一场 / 新一期妈妈班、门店活动、线下招募预告。全文必须写“接下来将发生什么”，不得写成往期复盘。

```
[1] 标题：突出一个预告钩子（亮点/福利/名额/体验），避免堆时间地点
[2] 开篇钩子：从 12 种方向里选 1 种自然切入
    - 悬念好奇 / 直击痛点 / 场景代入 / 福利吸引
    - 情感共鸣 / 稀缺提醒 / 专业价值 / 社交分享
    - 对比反转 / 用户想象 / 轻松闲聊 / 数字清单
    禁止固定用“新一期美素佳儿妈妈班……”作默认首句
[3] 活动总起：说明新一期活动将于 xx月xx号，在 xxx商城xxx楼 开展
[4] 核心亮点：展开 1-3 个最有吸引力的环节（如脱口秀、互动答题、抽奖、专家分享、茶点等）
[5] 福利价值：写清奖品/礼包/参与收获；可分点，但不要写成冷冰冰公告
[6] 适合人群 + 参与理由：让孕妈/宝妈判断“适不适合我、值不值得来”
[7] 结尾报名：名额有限 + 私信/报名提醒，制造不想错过的感觉
```

活动预告红线：
- 必须使用未来语态：你将会看到、届时现场将、接下来会、想象一下、现场还会准备……
- 正文必须出现时间和地点占位词，格式如“xx月xx号，xxx商城xxx楼”，不得省略。
- 禁止写“下个月”“下周”等明确相对时间词，统一用“下一次”“新一期”“接下来”。
- 禁止写“这次”“现在”“当前”等当前时态词，避免让文章像已发生或正在发生。
- 禁止复盘词：参加完、体验过、整场活动、现场大家都说、结束后反馈。
- 不能用“我”表达个人感受或过去记忆，只能介绍“下一场将有什么”。

## 字数控制

| 字数区间 | 适用 | 段落数 |
|---|---|---|
| 30-80 字 | 评论 / 简短预告 | 1-2 段 |
| 81-150 字 | 短分享 / 福利通知 | 2-3 段 |
| 150-250 字 | 标准种草 / 干货 | 3-5 段 |
| 250+ 字 | 走心长文 / 深度评测 | 5+ 段 |

---

## 段落留白规则

- 每段 ≤4 行
- 重点信息单独成段
- 段间空一行（小红书排版规则）
- 列表用 1️⃣2️⃣3️⃣ 或 - 而不用纯数字

---

## hashtag 选择策略

每条笔记 5-15 个，混合：
- **大词 1-2 个**（流量）：`#母婴` `#育儿`
- **品类词 2-3 个**（精准）：`#奶粉推荐` `#待产包清单`
- **细分词 2-5 个**（长尾）：`#转奶不拉肚` `#a2蛋白奶粉`
- **场景词 1-2 个**（情境）：`#新手妈妈` `#二胎妈妈`
- **品牌词 1 个**：`#美素佳儿`（如果 brief 要求）
