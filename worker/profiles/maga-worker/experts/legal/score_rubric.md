# 法律 AE 评分规则 (0/1)

## 评分维度

**单一维度**：是否命中广告法违禁词。

## 通过条件 (score=1)

- 全文（包括标题、正文、hashtag、配图说明）不包含 `corpus.yaml > 法律违禁词/替换词` 中的任何词
- 不包含明显的谐音 / 拼音 / 同义规避（如 "zui" "罪好"）
- 不含医疗宣称（如 "治疗 / 治愈 / 痊愈 / 防治 / 缓解 XX 病"）
- 不含绝对化承诺（如 "100%" "永久" "终身保障"）

## 失败条件 (score=0)

命中任一即 fail：

| 类型 | 示例 | 处理 |
|---|---|---|
| 绝对化用语 | 最、第一、绝对、极、唯一、首选 | 替换为相对表达 |
| 医疗宣称 | 治疗、治愈、防治、消炎、抗菌 | 删除或替换为体感描述 |
| 国家级用语 | 国家级、央视、特供 | 删除 |
| 权威背书未授权 | "XX 推荐"（未授权） | 删除 |
| 同行贬低 | "比 XX 更好" "吊打 XX" | 改为单独陈述自身 |
| 数字不可证 | 99%、几乎 100% | 改为定性描述 |

## 命中报告格式

```yaml
score: 0
hits:
  - word: <命中的词>
    location: <标题/段落/hashtag>
    context: <前后 10 字>
    suggestion: <平替建议>
verdict: fail
```

## 重写指引

如 score=0，将所有 `hits` 的 `suggestion` 提供给 GE，让其精准替换。**不要让 GE 整篇重写**，只改命中处。
