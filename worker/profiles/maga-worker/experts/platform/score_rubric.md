# 平台 AE 评分规则 (0/1)

## ⚠ 硬约束 (0/1) — 仅这两类导致 score=0

**只有命中真正的红线才算 fail，排版/钩子等软问题写在 suggestions 里而不是判 0。**

| 硬红线类别 | 例 |
|---|---|
| 平台违禁词 (来自 `corpus.yaml`) | 医疗暗示 / 母乳类擦边 / 安全保证 / 病痛词 |
| 外平台导流 | 微信号 / 抖音搜 / 淘宝旗舰店 / 加 V / 私 V / DY |

只要**没命中**上述两类硬红线，就 `score: 1`。

## 通过条件 (score=1) 完整版

- 全文不命中 `corpus.yaml > 平台不合规违禁词` 列表
- 不引用外平台名 / 不诱导加微信抖音等

满足以上即 `score: 1`。其余排版/钩子/emoji 等问题作为 `suggestions` 一并返回，但**不影响 0/1 判定**。

## 软建议（写进 suggestions 字段）

以下是希望但非必须，命中即写建议但 score 仍可为 1：

- 标题：≤20 字、含 1 个钩子词或 emoji（**位置不限**，"真香 / 救命 / 谁懂 / 绝绝子" 等在标题任意处都算钩子；标题尾部带 emoji 也算）
- 正文：≥3 段、平均段落 ≤4 行
- 正文 emoji：≥1 个 emoji 即可，不要求每段都有
- hashtag：5-15 个、与主题相关

## 失败报告（仅当真违规时）

```yaml
score: 0
hits:
  - rule: <硬红线类别>
    word: <命中词>
    location: <位置>
    suggestion: <平替>
verdict: fail
```

## 通过但有建议时

```yaml
score: 1
hits: []
suggestions:
  - "标题前段加个钩子词如「真香」效果更好"
  - "第3段稍长，可拆成两段"
verdict: pass
```

## 重写指引

精确替换命中处，不让 GE 整篇重写。优先级：医疗暗示 > 母乳擦边 > 导流。
