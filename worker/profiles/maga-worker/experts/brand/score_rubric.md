# 品牌 AE 评分规则 (0/1)

## 通过条件 (score=1)

1. **品牌识别词出现 ≥1 次**（标题或正文皆可）
2. **未命中品牌禁词**（含友商名）
3. **调性匹配 ≥2 个 brand_tone 标签**（如 brief 要求"专业可信" + "温和沟通"）
4. **品牌信息无事实错误**（历史/产地/配方/科研描述与 corpus 一致）

## 失败条件 (score=0)

| 情形 | 处理 |
|---|---|
| 品牌识别词缺失 | 在标题或首段补回 |
| 命中品牌禁词 | 替换或场景化转译 |
| 提及友商品牌名 | 删除或泛化为 "之前的奶粉" |
| 品牌信息出错 | 用 corpus 中的事实改正 |
| 调性偏离 | 重写偏离段落 |

## 报告格式

```yaml
score: 0
hits:
  - rule: <规则>
    location: <位置>
    suggestion: <修正>
verdict: fail
reason: <一句话说明>
```
